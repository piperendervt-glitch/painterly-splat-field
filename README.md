# painterly-splat-field

AI が生成した絵画的な 2D 画像から、ガウシアンの粒でできた絵画的な 3D 空間（three.js / WebGPU）を作り、歩いて探索できるようにするツール。

## 動かし方（GUI）

Windows では、リポジトリの `start.bat` をダブルクリックする。初回だけ必要なものを入れてから、ブラウザで GUI が開く。黒い窓を閉じると止まる。

手で起動する場合：

```
npm install
cd paint && npm install && cd ..
npm run studio
```

必要なもの：Node.js（LTS）、Chrome か Edge。絵画化には Codex CLI も要る（`paint/README.md`）。

GUI は上のタブで段を切り替える。

| タブ | すること |
| --- | --- |
| 1 プレビズ | 下絵の 3D を見る。「previz-export に保存」で、色・奥行き・カメラ情報を `previz-export/` に書く |
| 2 絵画化 | `previz-export/` を下絵に、Codex CLI（ChatGPT の月額プラン）で絵画を作る。下絵・絵画・重ねた確認の絵を並べて見る。結果は `paint/out/` |
| 3 粒の空間 | 絵の 1 画素を 1 粒として 3D 空間に置いて見る。回して見る／歩く（W A S D、プレビズの形で当たり判定） |
| 4 視点を足す | 穴（まだ絵に描かれていない面）が多く見える視点を足し、穴だけを埋めて、その分の粒を加える |
| 試作 | 最初の 1 枚絵ビューア（素材は別途 `prototype/` に置く） |

### SHARP で絵 1 枚から粒を作る（試し）

Apple の SHARP（絵 1 枚から 3D ガウシアンを推定するモデル）で作った粒を、「粒の空間」の「粒の置き方」で今の置き方と切り替えて見比べられる。モデルは研究目的のみ（非商用）のライセンス。手順は [sharp/README.md](sharp/README.md)（`sharp\setup.bat` → `sharp\run-jatte.bat` → `start-jatte.bat`）。

### 「粒の空間」の確かめ用の表示

- 粒の色のもと：絵画（最初の絵 / 光の少ない絵 / 影つきの絵）、プレビズの下絵（色 / 光なし / 影つき）
- 使う視点：すべて / 視点ごと。「A だけ」にしてカメラ B へ移り「穴を目立たせる」を入れると、A から見えなかった所がマゼンタで分かる
- 表示：絵のままの色 / 光を変えた後 / 奥行き / 種類 / 種類＋絵 / 札の境目 / 物体 / 面の向き / 視点別 / 日なた（元）/ 日なた（今）/ 揺れる粒
- 光を変える：時刻（0〜24 時）と「時間を進める」（1 日の長さは 20〜600 秒）、太陽の方位・高さ・強さ・色、空の光の強さ・色、明暗の段階、明るくする上限、時間帯の見本（描いたとき・朝・昼・夕・夜）
- 動き：風で揺らす（揺れ幅・速さ・向き）、歩くと足元の草がよける（範囲）、足跡を付ける、足跡をマゼンタで目立たせる、足跡を消す。それぞれ切れば元の絵に戻る
- プレビズの形を線で重ねる、カメラの視錐台、空の粒の出し入れ
- 粒の大きさ、境界の粒を消す量、粒の細かさ（全画素で約 310 万粒）
- 重ね順：並べ直す（視点が動くたびに遠い順。並べ直しは描画とは別の糸（Web Worker、`studio/sortworker.js`）で行うので、歩いても画面は止まらない）/ 固定（試作と同じ）/ 不透明（深度テスト）
- 描画方式（WebGPU / WebGL 2）、粒の数、fps、並べ直しにかかった時間

### 「粒の空間」で歩く

「歩く」を押すと、カメラの真下の地面に立つ。画面をクリックするとマウスで見回せる（Esc で解除）。

- W A S D か矢印で歩く、Shift で走る、Space で跳ぶ。重力あり、0.45 m までの段は上る、傾き 50° までの面に立てる
- 当たり判定はプレビズの形そのもの（`shared/collision.js`）。推定はしない。種類の一覧（`shared/labels.js`）の `solid` で、立てる（walk）・ぶつかるだけ（wall）・すり抜ける（none、木の葉など）を決める
- 確かめ用：当たりの形を表示（緑 = 立てる床、橙 = 壁、赤 = いま触れている所）、後ろから見る（自分の体の形と足元の輪。輪は立っていれば緑、空中なら赤）、当たり判定を切って飛ぶ（E で上、Q で下）、目の高さ、歩く速さ。右下の「足元」に、いま立っている面の種類と物体が出る
- 落ちても 40 m 下で、最後に立っていた所へ戻る

### 「視点を足す」の流れ

1. **視点を決める**：左の 3D の画面で候補のカメラを動かす。左ドラッグで回す、右ドラッグでずらす、ホイールで寄る・引く。緑の玉（カメラ）と白い玉（見る先）は、矢印を掴むと 3 方向へ動く。形をダブルクリックすると、そこが見る先になる。「カメラの目で見る」を押すと、画面の見え方がそのまま候補の視点になり（緑の枠の中が絵になる範囲）、回す・寄る・ずらすで候補が動く。「上からの地図」に切り替えると、今までの地図でも動かせる（クリックで位置、Shift＋クリックで見る先）。高さは「カメラの高さ」（200 m まで）、上下の向きは「見下ろす角度」（90 度で真下）で変える。「見る先の真上から見下ろす」で俯瞰の視点になる。右の絵は、その視点から見える面のうち、どの絵にも描かれていない所をマゼンタで示す。「穴の多い視点を自動で探す」は、まわりの位置を総当たりして、形（地面以外）の穴がいちばん多く見える所へ候補を移す。
2. **この視点を足す**：カメラを `previz-export/extra_cameras.json` に足し、プレビズをその視点からも書き出し直し、すでにある絵を新しい視点へ写す（`paint/out/<視点>_reproj.png`）。写せなかった画素が穴（`<視点>_holes.png`）。ここまでは ChatGPT の利用枠を使わない。
3. **穴を埋める**（どちらも穴の外は 1 画素も変えない。「埋める前 / 埋めた後 / 重ねて確認」で見比べる）
   - ツール内で埋める：まわりの色を同じ面の中だけで穴へ広げ、届かない面は、書き出しの札で見た「同じ物体（無ければ同じ種類）・同じ高さの平均の色」で塗る。数秒で終わるが、新しい模様は作れない。
   - Codex で描き足す：`paint.mjs fill` に、穴をマゼンタにした絵と同じ視点のプレビズを渡して描かせる。
4. 「粒の空間」で「ファイルを読み直す」を押すと、足した視点の **穴だった画素だけ** が粒として加わる（`<視点>_new.png` が印。「視点別」の表示で色が分かれる）。

上の「光の描き方」で、どの絵（自由 / 光の少ない絵 / プレビズの光に従う絵）を基準にするかを選ぶ。視点を足すと、絵のある描き方すべてについて写す。穴埋めは選んだ描き方の絵に対して行い、Codex にはその描き方の光の指示と下絵（`_flat` / `_lit`）を渡す。後から別の描き方の絵を描いたときは「すでにある絵を写し直す」。粒にする画素の印（`<視点>_new.png`）は描き方によらず 1 枚。

「穴かどうか」は、候補から見える点をすでに絵のある各視点へ映し、その視点の奥行きと合うか（同じ面が見えていたか）で決める。計算はすべて CPU（`studio/viewdata.js`）。

足した視点は `previz-export/extra_cameras.json` に残る。プレビズの画面は保存の前にこの一覧を確かめ、開いた後に視点が増減していたら読み直してから保存する。それでも書き出しから視点が消えていた場合は、「視点を足す」を開いたときに自動で書き出し直す（描いた絵は `paint/out/` に残っているので、描き直しは要らない）。

まだ無いもの：物体ごと・種類ごとの色替え、雪や季節、空を別の層にすること。

粒が持つ情報と光の式は [docs/splat-format.md](docs/splat-format.md)。

### 光の付け替えを見比べる手順

1. 「プレビズ」で「previz-export に保存」（種類・物体・面の向き・日なた・下絵2枚が増える）
2. 「絵画化」で「光の描き方」を「光の少ない絵」にして描く。次に「プレビズの光に従う絵」にして描く
3. 「粒の空間」で「ファイルを読み直す」。色のもとを「光の少ない絵」「影つきの絵」で切り替え、「光を変える」のつまみを動かして、「絵のままの色」と「光を変えた後」を押し比べる

絵画が無くても、色のもとを「プレビズの下絵」の「光なし」「影つき」にすれば同じ操作を試せる（下絵どうしなら、どちらの方式でも同じ結果になる）。

GUI のサーバーは Vite の開発サーバーに小さな API を足したもの（`studio/server.mjs`）。手元の PC の中（127.0.0.1）だけで動く。

## previz/ プレビズ書き出し

地面・アーチ1つ・奥の塔だけの下絵用シーン（`previz/scene.js`）。2つの視点（カメラA・B）から次を zip で書き出す。

| ファイル | 中身 |
| --- | --- |
| `A_color.png` `B_color.png` | 色（1024×1536） |
| `A_depth.png` `B_depth.png` | 奥行き。16bit を R（上位）G（下位）に格納 |
| `A_depth_view.png` `B_depth_view.png` | 目で見る用の奥行き（明るいほど手前、距離の対数） |
| `A_type.png` `B_type.png` | 種類の札。画素値が種類の番号（`shared/labels.js`）。0 は空 |
| `A_type_view.png` `B_type_view.png` | 目で見る用の種類の色分け |
| `A_object.png` `B_object.png` | 物体の札。番号 = R × 256 + G。0 は物体なし |
| `A_normal.png` `B_normal.png` | 面の向き（ワールド座標の法線）。n = rgb / 127.5 − 1 |
| `A_sun.png` `B_sun.png` | 下絵の太陽での日なた（255）と落ちる影（0） |
| `A_flat.png` `B_flat.png` | 絵画化の下絵「光なし」。物の色だけで、太陽も影も無い |
| `A_lit.png` `B_lit.png` | 絵画化の下絵「影つき」。白い太陽と落ちる影つき |
| `cameras.json` | 内部・外部パラメータと奥行きの式、種類と物体の一覧（`labels`）、下絵の光（`paint_light`） |

奥行きは視差を正規化した値で、`d = value / 65535`、`z = 1 / (d * (1/near - 1/far) + 1/far)`。`z` はカメラの向きに沿った距離（m）。値 0 は空。座標系と行列の向きは `cameras.json` に書いてある。

デバッグ表示：

- 視点：俯瞰 / カメラA / カメラB
- 表示：色 / 奥行き / 種類 / 物体 / 面の向き / 日なた / 光なし / 影つき（種類から右は、書き出す絵そのもの）
- カメラの視錐台（橙が A、水色が B）
- 書き出したデータだけから復元した点群（A＋B / A だけ / B だけ）。形を隠して「Aの点だけ」をカメラBから見ると、A から見えなかった裏側の穴が分かる。
- 描画方式（WebGPU / WebGL 2）の切り替えと fps
- 復元の誤差：書き出した奥行きを、形への当たり判定で求めた距離と比べた相対誤差

視点や大きさを変えるときは `previz/scene.js` の `EXPORT` を編集する。

形を足すときは、`previz/scene.js` の `label(形, 種類, 物体の名前)` で札を付ける。種類を増やすときは `shared/labels.js` の `TYPES` の末尾に行を足す。下絵の太陽の向きは `PAINT_SUN`。

## prototype/ 粒の絵画ビューア（試作）

1枚の絵を奥行き推定で粒に変換して覗き込む最初の試作。素材の `painting.jpg` と `depth.png` は参考の絵そのものなので、このリポジトリには入れていない（`.gitignore` 済み）。手元で試すときだけ `prototype/` に置く。

## painting/ 実在の絵から歩ける場面を作る

絵 1 枚から、奥行き・領域（種類）・カメラを推定して、プレビズの書き出しと同じ形式のデータを `scenes/<名前>/` に作る。元の視点は絵の画素をそのまま粒にする。

最初の場面はスーラ「グランド・ジャット島の日曜日の午後」（`scenes/jatte/`）。`start-jatte.bat` をダブルクリックして「粒の空間」のタブを開くと、絵の中を歩ける（`PSF_SCENE=jatte` を付けて GUI を起動しているだけ）。

作り直すとき：

```
cd painting
npm install
node build.mjs --image <絵のファイル> --scene jatte --horizon 0.2 --eye 1.7 --hfov 60
```

- `--horizon`：地平線（目の高さ）が絵の上から何割の所にあるか。`--eye`：目の高さ（m）。`--hfov`：絵の横の画角（度）。
- 奥行きは Depth Anything V2 Small（Apache-2.0、初回に GitHub から約 95 MB を取得）。地面の奥行きは地平線と目の高さから計算で決め、モデルの値はそれに合うように尺度を合わせて人や木に使う。
- 出力：`J_color.png`（プレビズ＝種類ごとの色）、`J_depth.png`、`J_labels.png`（種類：0 空 / 1 地面 / 2 水 / 3 人・動物 / 4 遠景 / 5 木）、`J_objects.png`（物体番号）、`J_overlay.png`（絵に境目を重ねた確かめ用）、`paint-out/J_painted.png`（絵そのもの）。
- 種類分けは奥行きと色だけで決めた下書きで、木の前に立つ人が「木」になるなどの間違いがある。

画像の出典：Georges Seurat, *A Sunday on La Grande Jatte — 1884*, The Art Institute of Chicago（[作品ページ](https://www.artic.edu/artworks/27992)）、CC0 Public Domain Designation。
