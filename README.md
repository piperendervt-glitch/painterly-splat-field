# painterly-splat-field

AI が生成した絵画的な 2D 画像から、ガウシアンの粒でできた絵画的な 3D 空間（three.js / WebGPU）を作り、歩いて探索できるようにするツール。

## 動かし方（GUI）

Windows では、リポジトリの `start.bat` をダブルクリックする。初回だけ必要なものを入れてから、ブラウザで GUI が開く。黒い窓を閉じると止まる。

手で起動する場合：

```
npm install
cd paint && npm install && cd ..
npm run studio
```

必要なもの：Node.js（LTS）、Chrome か Edge。絵画化には Codex CLI も要る（`paint/README.md`）。

GUI は上のタブで段を切り替える。

| タブ | すること |
| --- | --- |
| 1 プレビズ | 下絵の 3D を見る。「previz-export に保存」で、色・奥行き・カメラ情報を `previz-export/` に書く |
| 2 絵画化 | `previz-export/` を下絵に、Codex CLI（ChatGPT の月額プラン）で絵画を作る。下絵・絵画・重ねた確認の絵を並べて見る。結果は `paint/out/` |
| 3 粒の空間 | 絵の 1 画素を 1 粒として 3D 空間に置いて見る。回して見る／歩く（W A S D） |
| 試作 | 最初の 1 枚絵ビューア（素材は別途 `prototype/` に置く） |

### 「粒の空間」の確かめ用の表示

- 粒の色のもと：絵画（最初の絵 / 光の少ない絵 / 影つきの絵）、プレビズの下絵（色 / 光なし / 影つき）
- 使う視点：すべて / 視点ごと。「A だけ」にしてカメラ B へ移り「穴を目立たせる」を入れると、A から見えなかった所がマゼンタで分かる
- 表示：絵のままの色 / 光を変えた後 / 奥行き / 種類 / 種類＋絵 / 札の境目 / 物体 / 面の向き / 視点別 / 日なた（元）/ 日なた（今）
- 光を変える：太陽の方位・高さ・強さ・色、空の光の強さ・色、明暗の段階、明るくする上限、時間帯の見本（描いたとき・朝・昼・夕・夜）
- プレビズの形を線で重ねる、カメラの視錐台、空の粒の出し入れ
- 粒の大きさ、境界の粒を消す量、粒の細かさ（全画素で約 310 万粒）
- 重ね順：並べ直す（視点が動くたびに遠い順）/ 固定（試作と同じ）/ 不透明（深度テスト）
- 描画方式（WebGPU / WebGL 2）、粒の数、fps、並べ直しにかかった時間

まだ無いもの：当たり判定（壁をすり抜ける）、穴埋め、札を使った動き（揺れ、足跡）や物体ごとの色替え。

粒が持つ情報と光の式は [docs/splat-format.md](docs/splat-format.md)。

### 光の付け替えを見比べる手順

1. 「プレビズ」で「previz-export に保存」（種類・物体・面の向き・日なた・下絵2枚が増える）
2. 「絵画化」で「光の描き方」を「光の少ない絵」にして描く。次に「プレビズの光に従う絵」にして描く
3. 「粒の空間」で「ファイルを読み直す」。色のもとを「光の少ない絵」「影つきの絵」で切り替え、「光を変える」のつまみを動かして、「絵のままの色」と「光を変えた後」を押し比べる

絵画が無くても、色のもとを「プレビズの下絵」の「光なし」「影つき」にすれば同じ操作を試せる（下絵どうしなら、どちらの方式でも同じ結果になる）。

GUI のサーバーは Vite の開発サーバーに小さな API を足したもの（`studio/server.mjs`）。手元の PC の中（127.0.0.1）だけで動く。

## previz/ プレビズ書き出し

地面・アーチ1つ・奥の塔だけの下絵用シーン（`previz/scene.js`）。2つの視点（カメラA・B）から次を zip で書き出す。

| ファイル | 中身 |
| --- | --- |
| `A_color.png` `B_color.png` | 色（1024×1536） |
| `A_depth.png` `B_depth.png` | 奥行き。16bit を R（上位）G（下位）に格納 |
| `A_depth_view.png` `B_depth_view.png` | 目で見る用の奥行き（明るいほど手前、距離の対数） |
| `A_type.png` `B_type.png` | 種類の札。画素値が種類の番号（`shared/labels.js`）。0 は空 |
| `A_type_view.png` `B_type_view.png` | 目で見る用の種類の色分け |
| `A_object.png` `B_object.png` | 物体の札。番号 = R × 256 + G。0 は物体なし |
| `A_normal.png` `B_normal.png` | 面の向き（ワールド座標の法線）。n = rgb / 127.5 − 1 |
| `A_sun.png` `B_sun.png` | 下絵の太陽での日なた（255）と落ちる影（0） |
| `A_flat.png` `B_flat.png` | 絵画化の下絵「光なし」。物の色だけで、太陽も影も無い |
| `A_lit.png` `B_lit.png` | 絵画化の下絵「影つき」。白い太陽と落ちる影つき |
| `cameras.json` | 内部・外部パラメータと奥行きの式、種類と物体の一覧（`labels`）、下絵の光（`paint_light`） |

奥行きは視差を正規化した値で、`d = value / 65535`、`z = 1 / (d * (1/near - 1/far) + 1/far)`。`z` はカメラの向きに沿った距離（m）。値 0 は空。座標系と行列の向きは `cameras.json` に書いてある。

デバッグ表示：

- 視点：俯瞰 / カメラA / カメラB
- 表示：色 / 奥行き / 種類 / 物体 / 面の向き / 日なた / 光なし / 影つき（種類から右は、書き出す絵そのもの）
- カメラの視錐台（橙が A、水色が B）
- 書き出したデータだけから復元した点群（A＋B / A だけ / B だけ）。形を隠して「Aの点だけ」をカメラBから見ると、A から見えなかった裏側の穴が分かる。
- 描画方式（WebGPU / WebGL 2）の切り替えと fps
- 復元の誤差：書き出した奥行きを、形への当たり判定で求めた距離と比べた相対誤差

視点や大きさを変えるときは `previz/scene.js` の `EXPORT` を編集する。

形を足すときは、`previz/scene.js` の `label(形, 種類, 物体の名前)` で札を付ける。種類を増やすときは `shared/labels.js` の `TYPES` の末尾に行を足す。下絵の太陽の向きは `PAINT_SUN`。

## prototype/ 粒の絵画ビューア（試作）

1枚の絵を奥行き推定で粒に変換して覗き込む最初の試作。素材の `painting.jpg` と `depth.png` は参考の絵そのものなので、このリポジトリには入れていない（`.gitignore` 済み）。手元で試すときだけ `prototype/` に置く。
