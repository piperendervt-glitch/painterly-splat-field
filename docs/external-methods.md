# 一枚絵から歩ける 3D を作る外部手法の比較（グランド・ジャット島向け）

2026-11-18 時点。各手法の公開リポジトリの README とライセンス、Marble の公式ドキュメント、デモページの表示を読んで確かめた内容です。実際に動かしてはいません。「未確認」と書いた所は、読んだ範囲に書かれていなかった所です。

見るところは 5 つです。

1. **動ける範囲**：その場で見回せるだけか、歩いた先や物の後ろまで作るか
2. **出力**：今のツールの「外の世界の粒を取り込む」が読める 3D ガウシアンの `.ply` か（`.spz` は読めません。メッシュの `.ply` は頂点だけを点として読みます）
3. **動かす場所**：ブラウザだけで試せるか、手元の GPU でどれだけ要るか
4. **絵の保ち方**：スーラの点描がそのまま残るか
5. **ライセンス**

## 2. ジャット島で歩く目的から見た評価

- **物の後ろが要る。** 人物が 40 人以上いて、歩けばすぐ後ろへ回り込む。その場を見回すだけの手法（LucidDreamer・WorldGen・HunyuanWorld 1.0）は、絵の外側は広がるが、人の後ろは埋まらない。今のツールの「背後の層」と同じ弱点が残る
- **点描は、どの手法でも崩れるおそれが高い。** 動画生成で広げる手法（HY-World 2.0・Matrix-3D・FlexWorld・Voyager）は実写や CG で学習していて、細かい点の集まりを別の視点でも同じ点として保つのは苦手なはず。これは読んだ資料からは判断できず、実際に 1 回通して目で見るしかない
- **手元で現実的に動くのは 4 つ。** WorldGen（約 10 GB）、FlashWorld（9 GB なら遅い）、Matrix-3D（12〜19 GB、Linux なので WSL が要る）、LucidDreamer。GPU の型番が分かれば絞れる
- **今のツールとの相性がいちばん良いのは WorldGen。** 同じ SHARP を使い、出力は `.ply`。「10〜20° ずつ回して補完する」の代わりに、**360° を 1 回で一貫して描く**という別の解き方になっている
- **Marble は手間がいちばん少ない。** 当たり判定用のメッシュまで出るので、今の「推定した形」の代わりにもなる。ただし書き出しは有料

## 3. 試す順のおすすめ

費用と手間の少ない順に、目で見て見切りを付けていくのが良いと考えます。

1. **FlashWorld のデモ**（ブラウザ・無料・今動いている）：絵を入れて、点描がどう扱われるかを見る
2. **Marble の無料プラン**（ブラウザ）：作って中を見回すまではできる。良ければ Standard プランで `.ply` と当たり判定のメッシュを書き出し、今のツールに取り込む
3. **WorldGen を手元で**：SHARP の環境がすでにあるので入れやすい。360° のパノラマ方式が点描を保てるかを見る
4. 上のどれも点描が保てない場合：外部手法は「形と広がりの見本」として使い、絵は Codex に描かせる（止めてある、手順をこちらに移す案）

## 4. 取り込みで分かっていること

- 3D ガウシアンの `.ply` は「粒の空間」→「外の世界の粒を取り込む」で読める。Marble の座標は OpenCV 流（y が下、z が前）で、取り込みの「座標の決まり」の既定と同じ
- `.spz` は読めない。必要なら読み込みを足す
- Marble の当たり判定メッシュ（GLB）を歩くときの当たりに使うには、読み込みを足す必要がある
- 取り込んだ粒には種類の札が無いので、風・足跡・時間帯の光は今は効かない
